# 主题设计规范

> 版本 1 · 2026-10-13 · 适用于 DeskWidgets 的全部主题（目前：毛玻璃 Glass、像素 Pixel）。
> 新增主题、修改主题、给小组件做新画法之前，先读完这份文档。规范和代码不一致时：**先改规范，再改代码**。

用词约定：

- **必须**：硬性规定。违反会出 bug，或推翻用户已经确认过的决定（见附录 B）。
- **应该**：默认做法。有充分理由才能例外，例外要写进文末的「变更记录」。
- **可以**：自由发挥。

---

## 1. 什么是主题

主题 = 所有小组件共用的一整套外观：**卡片**（形状、材质、边缘）、**配色**（浅色、深色各一套）、**字体**、**图标**、**动效**。

主题**不决定**：小组件显示哪些信息、卡片尺寸和位置、怎么操作、文案。这些在所有主题里都一样（第 2 节）。

| 主题 | 枚举值 | 一句话 | 实现方式 |
|---|---|---|---|
| 毛玻璃 | `WidgetTheme.Glass`（默认） | 仿 Apple 小组件：实时模糊的薄玻璃，22 DIP 圆角，没有描边和阴影 | 组件的 XAML 内容 + `GlassBackdrop`（DWM host backdrop）+ `WidgetFrame` 的底色和高光层 |
| 像素 | `WidgetTheme.Pixel` | 不透明的像素画卡片，低分辨率逐像素绘制，整数倍放大，边缘永远是硬的 | 每个组件一个静态 `XxxPixelScene`，画在 `PixelCanvas` 上，由 `PixelSurface` 1:1 显示 |

切换入口：托盘菜单或任意小组件的右键菜单 →「Theme / 主题」。设置保存在 `settings.json` 的 `Theme` 字段。

## 2. 所有主题都必须遵守的规则

### 2.1 全局切换

- **必须**：主题是全局的，所有小组件一起切换，不支持一部分组件用毛玻璃、另一部分用像素。
- **必须**：切换立即生效，不用重启。宿主（`WidgetHost.SetTheme` → `WidgetWindow.ApplyTheme`）会用新主题重新创建每个组件。一个组件实例的 `WidgetContext.Theme` 在它的生命周期里不会变，所以组件自己不用处理主题切换。

### 2.2 尺寸与位置

- **必须**：每个尺寸的卡片占地固定：小 164×164、中 344×164、大 344×344（单位 DIP；中、大 = 两个小卡片加 16 DIP 间隔）。桌面网格吸附和已保存的位置都依赖这些尺寸，换主题不能打乱用户的桌面。
- **可以**：整数倍放大带来的少量偏差（像素主题在 125%、175% 缩放下比毛玻璃略大）。
- **必须**：内容画在卡片里面。窗口就是卡片，画到外面会被裁掉。
- **必须**：不为某个主题新增专属尺寸。

### 2.3 信息底线

主题可以换表现形式（圆环 ↔ 电池条、城市全名 ↔ 三字母代码），放得下时也可以多显示一点，但每个尺寸**不能少于**下表的内容：

| 组件 | 小 | 中 | 大 |
|---|---|---|---|
| 电池 | 单设备：图标、电量数字、充电状态，开启「显示设备名称」时加名称<br>多设备：2×2，每格是图标 + 电量（图形或数字）+ 充电状态 | 最多 4 个设备：图标、电量（图形 + 数字）、充电状态、名称（可关闭） | 最多 6 行：图标、名称、连接方式和状态、电量数字 |
| 时钟 | 星期、时间、日期 | 同小号 | 不支持 |
| 世界时钟 | 4 个表盘 + 城市标识（全名或三字母代码） | 4 个表盘，各带城市名、时间、当地日期 | 每城一行：表盘、城市名、与本地的时差（含今天/昨天/明天）、时间、当地日期 |
| 大文件夹 | 带文件夹名和项目数的标题；2×2 个格子 | 同样的标题；4×2 个格子 | 同样的标题；4×4 个格子 |

- 没有设备时显示空状态文案（`Strings.NoDevices`）。
- 开启「显示未连接的设备」时，未连接的设备要明显变暗，电量用「—」代替。
- 右键菜单里的选项（显示设备名称、显示秒针、更换城市……）在所有主题里效果相同。
- 大文件夹：
  - 每个格子是该项的图标加一行名称。项目比格子多时，最后一格变成堆叠：下面几项的四个小图标加「+K」，K = 项目数 − (格子数 − 1)。刚好 4、8 或 16 项时没有堆叠。项目按文件夹的排序方式排列（最新、名称、类型或手动）。
  - 状态：空（「将文件拖到这里」）；找不到文件夹（「找不到文件夹」：标题不可点击，拒绝放入文件）；拖入悬停（一层色调和一个说明放下后会怎样的标签：移动到、复制到、在其中创建快捷方式，混合拖入时是「添加到」）。
  - 点击某一项会打开它；点击标题或堆叠会打开面板。面板里单击选中（Ctrl 和 Shift 扩展选择），双击或回车打开，随处打字就是搜索，第一次 Esc 清空搜索、第二次关闭面板，底部显示路径和「已选择 n 项」。选中的项目可以拖出去。**用户在面板里操作时，面板一直开着**（重命名、移到回收站、放回原处、排序、搜索、选择、项目菜单、卡片菜单里的「重命名文件夹…」、属性、往卡片上拖放、拖出），**这些操作弹出的窗口也不会让它关闭**，无论是我们的还是资源管理器的：对话框、文件操作的进度或冲突窗口、UAC 提示。**用户离开它时才关闭：** Esc（搜索框里有字时按第二次）、再次点击卡片的标题或堆叠、按下其他任何卡片、点击桌面或别的程序的窗口、切换到别的程序（Alt+Tab、任务栏）。**打开了什么之后也会关闭：** 双击、回车、打开、以管理员身份运行、在资源管理器中显示、打开文件所在位置。重命名后，改名的那一项被选中；移除之后，被移除项后面的那一项被选中。
  - 放不下的名称由同一个共享函数 `NameShortener` 缩短，按主题自己的字体量宽度（2.9）。

### 2.4 颜色的含义

主题决定具体色值，但**不能改变含义**：

- 电量 ≤ 20% 且没在充电：红；省电模式：黄；其他：绿（和 iOS 一致）。
- 充电中：显示闪电标志。
- 世界时钟：当地 6:00–18:00 用白天表盘，其余时间用夜间表盘；秒针用橙色强调色。
- 时钟的星期用强调色（红或橙）。

每个主题的具体色值见第 8 节。

### 2.5 语言与文字

- **必须**：所有可见文字取自 `Strings`（English 默认 + 中文），不在组件里硬写文案。日期用 `Strings.Culture` 或明确的格式串。
- **必须**：城市名在两种语言下都用英文（用户决定）。
- **必须**：时间用 24 小时制 `HH:mm`。
- **必须**：字体要么能覆盖中英文，要么有回退方案，而且**同一串文字不能混用两种字号**（像素主题的做法：像素字体拼不出来的文字，整串改用宋体 12px 点阵）。
- **必须**：两种语言都要放得下。英文通常更宽，中文通常更高（像素主题里中文行高 12px，像素字体只有 5px 或 7px）。实在放不下时可以换更紧凑的写法（例：像素主题的中文日期写成「10/13」而不是「10月13日」），并记到第 4 节。

### 2.6 跟随系统

- **必须**：提供浅色、深色两套配色，系统切换时立即重绘。XAML 内容监听 `ActualThemeChanged`；`PixelSurface` 会自动重绘。
- **必须**：在 100%–200% 缩放和跨显示器 DPI 变化时都保持清晰。
- **应该**：用到透明效果的主题，要说明 Windows 关闭「透明效果」或开启节电模式时的样子（毛玻璃会变成纯色，属于正常现象）。

### 2.7 操作与可读性

- **必须**：整张卡片都能拖动，内容不能拦截指针事件。卡片里不放按钮、输入框、滚动区域；设置一律放进右键菜单。
  - **例外（2026-10-21 批准，仅限大文件夹）：** 大文件夹的格子和标题接受点击：按下和松开都在系统的拖动阈值之内。按下后移动得更远，不论从哪里开始，仍然是拖动卡片。大文件夹卡片还接受拖入的文件。它仍然没有按钮、输入框和滚动区域：搜索、选择、排序和重命名都在面板里，面板是一个单独的窗口。
- **必须**：纯装饰层设置 `IsHitTestVisible = false`。
- **必须**（不透明主题）：正文文字和背景的对比度 ≥ 4.5:1，大数字 ≥ 3:1。只用于刻度、分隔线的弱色（像素主题的 `Faint`）不能用来写正文。
- 毛玻璃的背景是实时的，无法保证对比度，见 4.1 的「已知取舍」。

### 2.8 性能

- **必须**：空闲时几乎不占 CPU。只在数据变化或时钟跳动（对齐到整秒或整分）时重绘；不写每帧都刷新的循环；过渡动画不超过 1 秒。
- **应该**：重用画布、位图和画刷，不要每次重绘都分配大对象。

### 2.9 代码分层

- **必须**：数据和文案放在共享层（`DeviceStatus`、`WorldCities`、`Strings`……），主题层只负责「画」。同一条信息在各主题里的写法由同一个共享函数产生（例：`WorldCities.FormatTime` / `FormatDate` / `DescribeOffset`），主题只能在放不下时做 2.5 里那种有记录的压缩。
- **必须**：每个主题的画法放在自己的文件里。毛玻璃 = 组件类里的 XAML 和代码；像素 = `Pixel/` 基础设施 + `Widgets/<组件>/<组件>PixelScene.cs`。新主题照此新建 `<主题名>/` 文件夹和 `<组件><主题名>Scene.cs`。
- **必须**：组件只用本主题调色板里的颜色角色（第 8 节），不在组件里写死色值。
- **应该**：没有专属画法的组件也能工作（它的 XAML 内容会直接放在当前主题的卡片上）。但正式发布的主题应该给每个组件都做专属画法。

### 2.10 素材来源

- **必须**：字体、图标、精灵图必须是原创、系统自带，或者许可允许再分发。不打包 Apple 的 SF 字体，也不从游戏截图里抠素材。现有主题只用了系统字体（Segoe UI Variable、Segoe Fluent Icons、宋体）和手绘的像素字体、精灵图。

## 3. 每个主题必须定义的设计令牌

同一类令牌集中放在一处，不要散落在各个组件里。

| 类别 | 要定义的内容 | 毛玻璃在哪里 | 像素在哪里 |
|---|---|---|---|
| 卡片 | 形状、圆角、材质、边缘、高光和阴影 | `Hosting/WidgetFrame.xaml`、`Hosting/GlassBackdrop.cs` | `Pixel/PixelCard.cs` |
| 配色 | 浅色、深色两套，按第 8 节的角色命名 | `Widgets/GlassPalette.cs` | `Pixel/PixelPalette.cs` |
| 字体 | 字族、字号阶梯、字重、回退字体 | Segoe UI Variable Display / Text | `Pixel/PixelFonts.cs`（3×5、5×7）+ `Pixel/SystemGlyphs.cs`（宋体 12px） |
| 图标 | 设备图标、充电标志、空状态图标 | Segoe Fluent Icons（`Widgets/Battery/DeviceGlyphs.cs`） | `Pixel/PixelSprites.cs` |
| 动效 | 哪些变化有动画、时长、曲线 | 电量环 700 ms 三次方缓出；秒针逐秒跳 | 没有补间，状态变化直接换帧；秒针逐秒跳 |

## 4. 各主题规格

### 4.1 毛玻璃 Glass

用户已确认（2026-10-12）：

- **薄、通透**：DWM host backdrop 实时模糊窗口背后的内容，上面只叠 24% 的底色（浅色模式白、深色模式黑）和一道斜向高光。
- **不加描边**（用户觉得卡片四周的白线难看），**不加阴影**（XAML 阴影会盖在系统层的玻璃上面，把它弄脏）。
- **不要用加厚底色来提高对比度**（「太厚」的版本被用户否决过）。
- 圆角 22 DIP，抗锯齿。

字号（现有取值，新组件就近选用）：

| 用途 | 字体 | 字号 / 字重 |
|---|---|---|
| 主角大数字（时钟时间、单设备电量） | Segoe UI Variable Display | 36–64，SemiBold |
| 列表大数字（世界时钟时间、列表电量） | Display | 17–28，SemiBold |
| 列表标题（设备名、城市名） | Segoe UI Variable Text | 14–15，SemiBold |
| 正文（名称、时间、中号电量） | Text | 11–15 |
| 辅助信息（日期、状态、时差） | Text | 11–12，次要色 |

**已知取舍**：玻璃很薄，所以在很暗的壁纸上，浅色模式的深色文字对比度会下降（反过来也一样）。改进方向（尚未实现）：根据卡片背后的亮度自动选文字颜色，而不是加厚底色。

**大文件夹**（2026-10-21 新增；尺寸单位 DIP）：

- **卡片：** 照常的毛玻璃卡片。标题在 y 12 到 30：文件夹名（Text 13 SemiBold，中间省略）、数量（Text 12，次要色）和一个箭头。格子：小 2×2（列宽 70，行高 60，图块 40），中 4×2（列宽 80，行高 60，图块 40），大 4×4（列宽 80，行高 75，图块 48）。名称一行，Text 11（大号 12），宽 74（小号 64）。
- **图标：** 每一项都放在圆角图块上（圆角 0.225 × 图块尺寸），带一层淡淡的光泽。14 种文件类型和第一批 13 个应用是我们自己画的（一种颜色加一个图案，绝不用 logo；路径数据在设计稿的 `ICONS.md` 里，经 `SvgPath` 绘制）。其他应用把它真实的图标放在 `Tile plate` 底板上，占图块的 0.68；图标本身已经铺满方形时则铺满图块。图片和视频显示真实缩略图并裁成图块形状（视频加播放标记）。仅在云端的文件绝不下载：在有缓存缩略图之前一直显示类型图块。
- **状态：** 悬停和按下的底板（`Hover`、`Pressed`）淡入 100 ms、淡出 150 ms；目标已经不存在的应用不透明度 40%，名称用次要色；空文件夹显示带下载图形的圆盘；找不到文件夹显示警告图形，每个尺寸都显示路径，中、大号再加提示「右键 › 选择文件夹…」；拖入时整张卡片罩上一层 `Drop tint`，并显示一个带动作的 `Select` 胶囊。
- **面板：** 440 × 500 的玻璃窗口，在卡片旁 12 DIP（放得下并留 8 的余量就放右边，否则放左边；会超出底部就上移）。它按 2.3 的规则关闭。标题和数量、排序按钮、搜索框、五列 80 × 92 的格子（名称两行），底部是路径和「已选择 n 项」。选中是 Finder 风格：图块下一块 `Pressed` 底板，每行名称下一个 `Select` 胶囊；键盘焦点是 2 DIP 的 `Select` 环。重命名是在名称位置上的一行文本框。
- **菜单：** 经 `MenuFlyout` 显示 `MenuEntry` 行，与其他组件一样。

### 4.2 像素 Pixel

2026-10-13 新增。

- **栅格**：1 个美术像素 = 2 DIP。卡片美术尺寸：小 82×82、中 172×82、大 172×172。
- **放大**：放大倍数 = round(缩放比例 × 2)，即 100% 为 2、150% 为 3、200% 为 4。位图按 1:1 显示，每个美术像素必须是一块 N×N 的纯色方块：不滤波、不抗锯齿、不用小数坐标。大数字只按整数倍放大（×2、×3）。
- **卡片**：不透明面板。1px 描边；圆角是台阶状（从上往下依次内缩 4、2、1、1 像素）；顶部 1px 高光，底部 2px 阴影。像素主题下毛玻璃的模糊层隐藏。像素卡片的描边是像素画风格的一部分，和毛玻璃「不加描边」的决定不冲突。
- **配色**：基于 Sweetie 16 色板，浅色（day）、深色（night）两套。组件只能用 `PixelPalette` 里的角色。
- **字体**：手绘的纯大写像素字体两套。
  - 3×5（`PixelFonts.Small`）：标签、名称、小数字。
  - 5×7（`PixelFonts.Regular`）：数值、标题；大数字用它 ×2 或 ×3。
  - 小写字母自动转大写，重音去掉（São → SAO）。
  - 像素字体拼不出来的文字整串改用宋体 12px 点阵（`PixelFonts.System`），所以布局要给中文留出 12px 行高。
  - 两套字体都有反斜杠，所以像 `C:\Users\asus\Work` 这样的路径不需要回退字体。
  - 中文行不会以开引号类标点（“ （ 「 『 《）结尾：这个标点会和它引出的文字一起换到下一行。
- **图标**：`PixelSprites` 里的手绘精灵；未连接的设备变暗；充电时电池条上叠一个带描边的闪电。
- **布局**：坐标都用美术像素；内容离卡片边缘至少 7 像素；分隔用点线（`PixelCanvas.DottedLine`）。
- **动效**：没有补间动画，状态变化直接换帧；秒针逐秒跳。
- **已记录的压缩写法**：
  - 世界时钟小号用三字母城市代码（NYC、LAX、STJ、PEK……）。
  - 中文日期写成「10/13」。宋体的「10月13日」约 48 像素宽，放不进中号 39 像素的列。
  - 大文件夹，宋体度量：文件夹名或任何可见的项目名需要宋体时，整张卡片都用宋体的度量，所以 12 像素高的标题在小、中号卡片上位于 y 5（边距 5 像素，而不是通常的 7），格子的行移到 y 19 和 48。
  - 大文件夹，名称缩短：缩短后的名称在「…」前至少保留 2 个字符（拉丁文 3 个）；更少时丢掉尾部，从末尾截断（「腾讯会议」变成「腾讯…」）。
  - 大文件夹，扩展名：显示扩展名时，缩短后的名字尾部是扩展名加扩展名点前的 2 个字符（`cro…ve.txt`，不会是 `cross-dri….txt`）。两行显示时先在「-」「_」后断行，再在扩展名的点前断，只有这些都放不下才在单词中间断（`cross-` / `drive.txt`）。一个名字只用一种字体：中文整串用宋体，哪怕缩短后的片段只剩数字。
  - 大文件夹，找不到文件夹：没有提示行，路径只在大号上显示。
- **菜单与对话框**（2026-10-20 新增）：像素主题下，应用自己画的所有界面，不只是卡片，都和卡片一个风格。毛玻璃保持原来的 `MenuFlyout`、Win32 托盘菜单和 MessageBox。条目、顺序、文案和效果不变（第 2 节），只换外观。
  - **画法：** 小组件菜单、托盘菜单和两个对话框都是我们自己的无边框弹出窗口（`PixelUi/`），按与卡片相同的倍数 1:1 显示一块 `PixelCanvas`。文字用手绘字体（经 `PixelText`），拼不出的回退到宋体。小组件菜单和托盘菜单由同一份 `MenuEntry` 列表生成，毛玻璃把它转成 WinUI 弹出项或 Win32 菜单。
  - **边框：** 套用 `PixelCard` 的面板算法到任意矩形：1px 描边、底色、顶部 1px 高光、底部 2px 阴影边。圆角台阶：菜单 [2, 1]，对话框 [4, 2, 1, 1]，按钮 [1]。只有菜单和对话框带硬阴影（面板自身形状，向右下偏移 2 个美术像素，角色 `Shadow`，不模糊）；卡片仍然没有阴影。
  - **菜单行：** 面板里的标签都是像素字体时行高 15 个美术像素，只要有一个标签要用宋体就是 18（每个面板一个行高）；分隔线 7。前导列在 x 4（勾 7×6、单选菱形 5×5 或 7×7 图标，一行不会同时有两个），标签在 x 14，用 `PixelFonts.Regular`，子菜单箭头 3×5。宽度 = 14 + 最宽标签 + （有子菜单行时 16，否则 8），最小 64。子菜单悬停 250 ms 后展开，点击、右方向键或回车则立即展开，描边与父菜单共用一列，第一行与父行对齐。
  - **状态：** 鼠标所在行和键盘当前行是同一个高亮（`Select`，文字 `OnSelect`）；按下用 `SelectPressed`；有焦点的子菜单的父行用 `OpenFill`；禁用行用 `Faint`，不会高亮，键盘跳过；状态行用 `Soft`，不可聚焦。**对 2.7 的例外：** 禁用标签用 `Faint` 是有意的，禁用文字没有对比度要求，而且必须看起来不可用。
  - **长列表：** 面板比所在显示器的工作区还高时，裁成整行，并在两端各加一个 9 像素的滚动行（滚轮每格滚一行，悬停滚动行每 100 ms 滚一行，当前行总会滚进视野，打开时已选的那行可见）。滚动行即使那个方向没有更多内容也保留位置，所以滚动时面板高度不变。
  - **对话框：** 宽 172 个美术像素（大卡片的宽度）；标题条带应用标志和名称（拖标题条可移动对话框）；13×13 徽章（提问是带「?」的 `Select` 圆盘，警告是黄色三角）；文字用 `PixelFonts.Regular`；按钮高 17（宋体时 18）。默认按钮是主按钮（`Select` 底色）；退出确认打开时焦点在「否」，Esc 回答「否」（错误框里是「确定」），Y 和 N 直接回答，Tab 和方向键移动焦点。对其所属的小组件模态，居中在它所在的显示器上，置顶。
  - **动效：** 无。菜单、子菜单和对话框一帧出现、一帧消失。
  - **键盘与 Narrator：** 方向键、Home/End、回车/空格、Esc 和左右键的用法与原生菜单相同；弹出窗口提供 UI Automation 角色（菜单、带 Toggle / SelectionItem / ExpandCollapse 模式的菜单项、带按钮的对话框）。
  - **托盘图标：** 像素主题有自己的图标（深色台阶瓷砖、硬边圆环和像素鼠标），按显示器缩放对应的小图标尺寸精确绘制，切换主题或缩放时即时替换；exe 自带的图标不变。
- **大文件夹**（2026-10-21 新增；所有数字都是美术像素）：
  - **卡片：** 照常的面板。标题里文件夹名用 `PixelFonts.Regular`（`Ink`）在 x 7，数量（`Soft`）右对齐，离边缘 7。格子宽 36：16×16 的图标下面一行 `PixelFonts.Small` 的名称。列在 x 4 和 42（小号）或 5、47、89 和 131（中、大号）；行在 y 19 和 52（小、中号）或 19、60、101 和 142（大号）。堆叠是四个 7×7 的小图（图标的代表色，外面 1px 墨色描边）和「+K」。
  - **状态：** 悬停用 `Open fill`，按下用 `Shade`，内容下移 1px；标题也用同样的底板。目标不存在时图标变暗（墨色变 `Faint`，其他颜色变 `Track`），名称用 `Faint`。空：带落点箭头的点线矩形和「将文件拖到这里」。找不到文件夹：警告精灵和「找不到文件夹」。拖入悬停：面板底色的像素隔一个变成 `Select`，并显示一块写着动作的 `Select` 底板。
  - **图标：** 14 个文件类型精灵和 13 个应用精灵，16×16，用第 8 节的 16 个固定精灵色。其他应用：真实图标缩小到 14×14（「第二层」：盒式滤波，按 redmean 距离取最近的 Sweetie 色，不抖动，外面 1px 墨色描边）。照片和视频：中间的正方形缩小到 12×12，4×4 Bayer 抖动，外面是白色相纸边和切掉四角的墨色描边（视频加播放标记）。真实图片到来之前显示该类型的精灵。
  - **面板：** `PixelPopupWindow` 里 220 × 196 个美术像素（圆角台阶 [4, 2, 1, 1]，带对话框那样的硬阴影），离卡片 4 个美术像素（放得下放右边，否则左边，再不行盖在卡片上）。一行是文件夹名和「n 项」；一行是搜索框（凹槽、放大镜、1px 光标）和排序按钮（文字和箭头）；然后是五列格子（横向间距 41，纵向 33，宋体度量时 45），名称两行用 `PixelFonts.Small`，3px 滚动条，点线，底部（路径用 `Soft`，「已选择 n 项」用 `Ink`）。选中的格子是 `Select` 底板加 `OnSelect` 文字；键盘焦点是点线环；滚轮每格滚一行。
  - **行为：** 与毛玻璃相同（2.3）。随处打字就是搜索（Backspace 删一个字符）；输入框通过系统的文本服务接收文字，所以拼音输入法（候选框开在输入框旁边）、表情面板和 Ctrl+V 都能用，表情在名字里保持完整；F2 就地重命名，输入框出现在格子或标题行里；Delete 把选中项送进回收站；F4 或 Alt+↓ 打开排序列表。Esc 先取消重命名，再清空搜索，最后关闭面板。面板按 2.3 的规则关闭：它自己的菜单、对话框和文件操作窗口出现时不关，别的程序拿到前台时才关。选中的项目经 OLE 拖出，资源管理器和桌面接受它的方式与接受资源管理器自己的拖动相同。
  - **键盘与 Narrator：** 面板是一个窗口，里面有搜索框（Edit，带 Value 模式）、排序按钮（ExpandCollapse）和每个显示的项目一个列表项（Invoke 和 SelectionItem）。
  - **菜单：** 项目菜单和组件自己的菜单行用上面说的像素菜单。

## 5. 新增一个主题

1. **先设计**：按附录 A 填写设计简报，写进第 4 节。做出静态预览（每个组件 × 每个尺寸 × 浅/深 × 中/英），给用户确认后再写代码。
2. **写代码**：
   - 在 `WidgetTheme` 枚举末尾加值。名字会以文本形式存进 `settings.json`，定了就不能改名。
   - 在 `Strings.ThemeName` 里加中英文名称。托盘菜单和右键菜单会自动列出新主题。
   - 卡片：改 `WidgetFrame.SetCard`。需要实时模糊才调用 `GlassBackdrop.SetVisible(true)`。如果卡片的像素尺寸不是「DIP × 缩放」，同时修改 `WidgetLayout.GetCardPixels`。
   - 调色板：新建一个类，第 8 节的角色要齐全，浅、深两套。
   - 每个组件：在构造函数里按 `context.Theme` 选择画法，覆盖它支持的全部尺寸。
   - 预览：仿照 `Pixel/PixelPreview.cs`，让新主题也能一条命令导出全部布局的总览图。
3. **写文档**：更新 README 的简介和操作表、本文件第 4 节，以及文末的变更记录。
4. **验收**：第 7 节全部通过。

## 6. 修改现有主题

### 6.1 改动分级

| 级别 | 例子 | 要求 |
|---|---|---|
| 微调 | 间距 ±1–2、同一角色内换色、措辞 | 跑第 7 节的相关检查，写变更记录 |
| 主题内改版 | 某个尺寸换布局、换图标或字体、调整动效 | 给用户看改动前后的对比图；更新第 4 节 |
| 共享规则变更 | 卡片尺寸、显示哪些信息、颜色含义、交互方式、文案、设置字段 | 先问用户；所有主题在同一次改动里一起改；更新第 2 节 |
| 推翻用户决定 | 例如给毛玻璃加描边或阴影、把城市名改回中文 | 必须先得到用户明确同意 |

### 6.2 其他规则

- **兼容**：已经存进 `settings.json` 的标识不改名、不删除：
  - `TypeId`：battery、clock、worldclock、folder
  - 枚举名：`WidgetTheme`、`WidgetSize`、`AppLanguage`
  - 选项键：showNames、showDisconnected、cities、showSeconds；大文件夹的是 `path`、`sort`（newest、name、type 或 manual）和 `order`（文件名的 JSON 数组，手动排序用）

  新增选项的默认值必须保持原有行为。
- **多人协作**：可能有好几个会话同时在改这个仓库。
  - 改文件前重新读一遍。
  - 保持每个文件原有的换行符（仓库里 CRLF 和 LF 混用）。
  - 不顺手格式化没改动的代码，不回退别人的改动。
- **留证据**：每次视觉改动都附上截图或预览图。
- **记录**：在文末「变更记录」写一行：日期、主题、改了什么、为什么。

  - 中文回退字体

- [ ] 拖动和右键菜单正常。
- [ ] 空闲时 CPU 接近 0。

  3. 测完恢复用户原来的设置，重新启动程序。
- 截取桌面上真实的组件：小组件常被别的窗口挡住，普通截屏拍不到。用开启 Per-Monitor V2 DPI 感知的进程调用 `PrintWindow(hwnd, PW_RENDERFULLCONTENT)`。注意：这样截不到毛玻璃的模糊效果。
